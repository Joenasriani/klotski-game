# Klotski

**In-game title:** 3D Klotski Puzzle  
**Status:** original browser adaptation of the Klotski sliding-block puzzle  
**Play:** https://joenasr.itch.io/klotski  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Klotski is a 3D browser sliding-block puzzle based on the classic Klotski and Hua Rong Dao format. Players move constrained blocks through a compact board and plan a route for the main block to reach the exit.

The project is a browser game adaptation of the established puzzle type. The title **3D Klotski Puzzle** and **Klotski** refer to the same game lineage.

Existing branches and historical files are retained as development history.
